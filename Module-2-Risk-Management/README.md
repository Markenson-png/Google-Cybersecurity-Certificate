# Module 2: Play It Safe - Manage Security Risks

## 🌟 Introduction
This module shifted focus from general foundations to the strategic side of security: identifying vulnerabilities, analyzing threats, and understanding risk management frameworks.

## 🏛️ Frameworks & Core Theories
*   **The CIA Triad:**
    *   *Confidentiality:* Ensuring only authorized people access sensitive data.
    *   *Integrity:* Making sure data is accurate and has not been altered maliciously.
    *   *Availability:* Guaranteeing systems and data are up and accessible when needed.
*   **NIST Cybersecurity Framework (CSF):**
    *   Learned the five core pillars: **Identify, Protect, Detect, Respond, and Recover** to manage organizational risk.
*   **Security Controls:**
    *   *Administrative:* Policies and training (e.g., employee security awareness).
    *   *Technical:* Software safeguards (e.g., firewalls, encryption).
    *   *Physical:* Tangible security measures (e.g., security badges, locked server rooms).
